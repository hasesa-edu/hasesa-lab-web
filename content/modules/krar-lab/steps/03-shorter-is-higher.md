## Do: slow it down (10 minutes)

A string vibrates too fast to count. Something longer and looser is easier. Hold a 30 cm ruler flat on the table with 20 cm sticking out over the edge. Flick the end.

1. Can you count the vibrations? Film it in slow motion if a phone can.
2. Make the overhang shorter (15 cm, then 10 cm). What happens to the speed of the vibration, and to the sound?

The ruler and the string follow the same rule. Shorter means faster, and faster means higher.

## Theory: frequency and period

Read **Frequency and period**. You'll learn:

- that frequency $f$ is the number of vibrations each second, in hertz,
- that the period $T$ is the time for one vibration,
- that $T = \dfrac{1}{f}$, so a high note has a very short period,
- how to change between Hz and kHz, and between seconds and milliseconds.

Work out the period of your first reading from step 2. A 260 Hz string has a period of $1 \div 260 = 0.0038$ s, about 4 ms.

## Do: change the length (35 minutes)

Keep the **same** line and the **same** 1.5 L bottle all the time. Glasses on.

1. Slide the movable pen under the line so the vibrating length (from the fixed bridge to the pen) is 60 cm. Pluck **between** the fixed bridge and the pen, and read the frequency.
2. Read it three times. Write all three.
3. Repeat for 50, 40, 30, 25 and 20 cm.

Use this table:

| Length $L$ (m) | $f$ reading 1 (Hz) | reading 2 | reading 3 | mean $f$ (Hz) | $1/L$ (1/m) | $f \times L$ |
|---|---|---|---|---|---|---|
| 0.60 | | | | | | |
| 0.50 | | | | | | |
| … | | | | | | |

## Notice something puzzling

Plot mean $f$ (y-axis) against $L$ (x-axis). You get a curve that bends. Halving the length from 60 cm to 30 cm: what happened to the frequency? Now look at the last column. What do you notice about $f \times L$?

## Theory: graphs and relationships

Read **Graphs and relationships**, especially the section on straight lines through the origin. If $f \times L$ stays the same, then $f$ is **proportional** to $\dfrac{1}{L}$.

## Do it better: straighten the curve (20 minutes)

1. Fill in the $1/L$ column. For 0.25 m, $1/L = 1 \div 0.25 = 4$ per metre.
2. Plot mean $f$ (y-axis) against $1/L$ (x-axis). Start both axes at zero.
3. Draw **one** straight line of best fit. Does it pass close to the origin?
4. Find the gradient. Pick two points far apart **on your line**: gradient $= \dfrac{\text{rise}}{\text{run}}$. Its unit is Hz × m.

## Use your graph: predict (10 minutes)

Choose a note from the tuner's list, for example A = 440 Hz. Use your line (or $L = \text{gradient} \div f$) to predict the bridge position that will play it. Put the pen there and measure.

How close did you get, in percent? $\text{error} = \dfrac{\text{measured} - \text{target}}{\text{target}} \times 100$.
