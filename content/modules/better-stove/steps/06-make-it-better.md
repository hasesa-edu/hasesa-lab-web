## Choose one change (15 minutes)

Pick **one** change you think will make your stove better. Choose from:

- **Pot skirt:** with the skirt and without it.
- **Gap under the pot:** 1 cm and 3 cm (bend or swap the pot supports).
- **Insulation:** ash and sand (you'll need a second stove, identical except for the filling; pair up with another team).

Read **Fair tests and averages** again and write a five-line plan:

1. The question: *Does … change the time to boil / the wood used?*
2. Independent variable (the one thing you change).
3. Dependent variable (what you measure): time to boil 1 kg of water, wood burnt, or both.
4. Control variables (everything you keep the same). List at least five.
5. How many repeats, and in what order.

Predict which setting will win, and **why**, using conduction, convection or radiation.

## The problem with a warm stove

The first run of the day starts with a cold stove. A cold stove soaks up a lot of heat into its cans and ash before the pot gets much. The second run starts with a hot stove and does better, even if you changed nothing.

How do you keep it fair? Two ways:

- **Alternate:** run A, B, A, B. Start every run with fresh cold water from the same container, and start the first one only after a warm-up fire of 5 minutes.
- **Twin stoves:** for the insulation test, run the two stoves side by side at the same time.

## Do (50 minutes)

Each run: 1.000 kg of fresh water, starting temperature recorded, a weighed bundle of sticks, temperature every 2 minutes, stop at the boil, weigh the wood left. Your guide puts the fire out between runs only if the plan needs it; change the pot with gloves and tongs.

Aim for **at least two runs of each setting**.

| Run | Setting | Start temp (°C) | Time to boil (min) | Wood burnt (g) |
|---|---|---|---|---|
| 1 | A | | | |
| 2 | B | | | |
| 3 | A | | | |
| 4 | B | | | |

## Analyse (20 minutes)

1. Calculate the **mean** and **range** of time to boil and of wood burnt for each setting.
2. Draw a bar chart of the means, with the range shown as a line on each bar.
3. Is the difference between the means bigger than the ranges? If not, can you really say one is better?
4. Was your prediction right? Explain the result with heat transfer: where does the heat go in each setting?

## Record

Your plan, your table, means and ranges, your bar chart and a conclusion of two or three sentences that uses your numbers. Keep the better setting on your stove for the final session.
